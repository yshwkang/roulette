# 🎲 의사결정 룰렛

점심 메뉴처럼 고르기 어려운 결정을 룰렛을 돌려 정해주는 웹 앱입니다. 설치나 빌드 없이 브라우저에서 바로 동작하며, 스마트폰에서도 한 화면에 보이도록 만들었습니다.

## 링크

- GitHub 저장소: https://github.com/yshwkang/roulette
- 배포 사이트 (GitHub Pages): https://yshwkang.github.io/roulette/

## 주요 기능

- **룰렛 돌리기**: 버튼 한 번으로 룰렛이 돌고, 12시 방향 화살표가 가리키는 항목이 당첨됩니다.
- **가중치**: 항목마다 가중치(1~10)를 주면 칸이 커지고 당첨 확률도 높아집니다.
- **프리셋**: 기본 프리셋(점심 메뉴 모음, 가위바위보 대신)과 직접 만든 프리셋을 골라 쓸 수 있습니다.
- **항목 편집**: 항목의 이름, 색상, 가중치를 바꾸고 항목을 추가하거나 삭제할 수 있습니다. (항목 2~12개)
- **프리셋 편집**: 새 프리셋을 추가하거나 삭제하고, 수정한 기본 프리셋을 원래대로 되돌릴 수 있습니다.
- **자동 저장**: 프리셋과 편집 내용, 마지막으로 고른 프리셋이 브라우저(localStorage)에 저장되어 새로고침해도 유지됩니다.
- **모바일 대응**: 화면 크기에 맞춰 룰렛 크기가 조절됩니다.

## 사용법

1. 배포 사이트에 접속합니다.
2. **프리셋 선택**에서 원하는 프리셋을 고릅니다.
3. **돌리기!** 버튼을 누릅니다. 룰렛이 멈추면 당첨 항목이 팝업으로 표시됩니다.

### 항목 바꾸기

1. 상단의 **항목 편집** 버튼을 누릅니다. (창 제목에 현재 프리셋 이름이 표시됩니다.)
2. 색상, 이름, 가중치를 수정합니다. 변경 내용은 룰렛에 바로 반영되고 자동 저장됩니다.
3. **+ 항목 추가**로 항목을 늘리고, ✕ 버튼으로 삭제합니다.
4. ✕ 버튼, 창 바깥 클릭, Esc 키로 창을 닫습니다.

### 프리셋 만들기 / 삭제하기

1. 상단의 **프리셋 편집** 버튼을 누릅니다.
2. 새 프리셋 이름을 입력하고 **새 프리셋 추가**를 누르면 `항목-1`, `항목-2`, `항목-3`으로 시작하는 프리셋이 만들어지고 자동으로 선택됩니다. 이후 **항목 편집**에서 내용을 채웁니다.
3. 직접 만든 프리셋은 **선택 프리셋 삭제**로 지울 수 있습니다. 기본 프리셋은 삭제할 수 없고, 수정했다면 **기본값 복원**으로 되돌릴 수 있습니다.

> 룰렛이 도는 동안에는 편집 버튼이 잠깁니다. 저장 데이터는 사용 중인 브라우저에만 보관되며 다른 기기와 공유되지 않습니다.

## 직접 실행하기

빌드가 필요 없습니다. 저장소를 받아 `index.html`을 브라우저에서 열면 됩니다.

```bash
git clone https://github.com/yshwkang/roulette.git
cd roulette
# index.html 을 브라우저로 열기
```

## 기술 스택

HTML, CSS, JavaScript(Canvas 2D). 외부 라이브러리 없이 [index.html](index.html) 한 파일로 구성되어 있습니다.
